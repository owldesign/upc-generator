# upc-generator

Static UPC / EAN barcode generator for https://upc-generator.owl-design.net

Formats: Smart, UPC-A, UPC-E, EAN-13, EAN-8. GS1 mod-10 check digit. Optional 2/5-digit supplement, title text, short height. Export PNG/JPG/SVG/PDF or print at actual size.

Hosted on Freestyle owl-tools CT 105 (`192.168.88.21`), public via Pangolin. Design comps ship as `public/index.html` (self-contained).
